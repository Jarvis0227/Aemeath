# Default comment avatar

Generated with the built-in imagegen tool on 2026-10-20, then resized to 256 × 256 WebP (4,984 bytes) for the comment UI.

Prompt: A very cute original pink pig head, front-facing and centered, chubby round cheeks, small floppy ears, friendly dark eyes, rosy blush, rounded snout and a subtle smile. Soft kawaii cartoon with restrained outlines and pastel shading on a pale cream background. Large clear face, readable at 36 × 36 pixels and safe within a circular crop. No body, accessories, text, watermark, border, UI, or variants.

The local fallback is used when a visitor has no avatar or an avatar request fails. Libravatar's documented `d=404` option is used to detect a missing avatar instead of displaying its default logo: https://wiki.libravatar.org/api/
