# 关于我 / About Me

大家好，我是一名聚焦效率工具与 AI 工程化的开发者 **Rain**，同时拥有跨境电商运营的一线业务经验。

我习惯从真实业务痛点出发写代码：从用 React + TypeScript 搭建轻量化前端应用，到编写 ExtendScript 实现 Photoshop 批量素材处理，再到打通 Shopee、TikTok 与 BigSeller ERP 的多平台商品自动上架系统，我始终认为技术的价值最终要体现在效率提升与业务结果上。

目前我的核心探索方向是 AI 与跨境电商的结合，包括 AI 主图质量评估、自动化文案生成、多平台数据同步等场景。除此之外，我也对开源工具、网络安全与逆向工程有浓厚兴趣，享受从底层原理到上层应用逐层打通的过程。

这个博客是我的技术笔记与思考自留地，会不定期更新项目复盘、踩坑经验与商业化思考，欢迎同好交流。
