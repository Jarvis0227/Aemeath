# 站点双主题

导航栏的“主题”入口可以切换 Aemeath 与 Pure；Pure 中入口为导航栏右侧的主题图标，与搜索、深浅色按钮并列，菜单内可调整字体。默认使用 Aemeath，访客选择存入 `rainzt.site-theme.v1`；浅色 / 深色仍使用原有 `theme` 设置，两者互不覆盖。Pure 的强调色同样继承原项目的 `themeColor.hue`、访客保存的色相和节日主题设置。`src/config/siteThemeConfig.ts` 可以设置默认主题或关闭选择入口。

Pure 的独立导航、文章列表、标签侧栏、阅读栏、目录和页脚按 [Astro Theme Pure](https://github.com/cworld1/astro-theme-pure) 的布局适配。首页采用上游 Blog 页而非作者主页，正文标题按本站习惯显示“主页”；卡片封面保留右侧渐隐背景，透明度提高为 38%，同时加深简介文字以保持可读性。参考上游 `src/layouts/BaseLayout.astro`、`src/pages/blog/[...page].astro`、`packages/pure/components/basic/Header.astro` 与 `packages/pure/components/pages/PostPreview.astro`，保留 Apache-2.0 归属；上游许可随附于 `docs/licenses/astro-theme-pure-LICENSE.txt`。适配使用现有 Astro 7、Tailwind 与内容字段，不引入上游的演示文章或独立的内容集合。字体沿用项目的 `FontSetup`、`fontConfig` 与 `firefly-font-mode`，Pure 的主题菜单同样可选择默认字体 / 霞鹜文楷。

文章、友链、评论和配置只有一份，路由不变。`MainGridLayout` 先生成原有页面内容；Pure 首次解析时将唯一的 `#swup-container` 挂到独立布局里，原布局隐藏并设为 inert。因此评论 ID、加密文章、Svelte islands 和 Pagefind 元数据不会重复。首页两种列表展示相同的分页数据。

切换主题进行完整文档导航，释放上一套布局的组件和动画。Pure 的站内导航使用 Astro 客户端路由，保留同一个导航栏元素及其字体组件，只替换页面内容；Aemeath 继续沿用原有 Swup 行为。Pure 中不播放 Aemeath 的开屏、樱花和推荐卡片粒子动画。

Pure 正文使用一次 160ms 交叉淡入淡出，不进行整页平移，也不在请求开始时预先隐藏旧页面。导航栏通过 `transition:persist` 保留原 DOM，通过 `pure-header` 独立命名并置于页面视图图层上方，排除正文动画；导航栏不执行退场、入场、透明度或位置动画。页面替换前先挂载唯一正文并保留已加载的 Pure 样式，避免截取隐藏页面或移除样式造成闪烁。正文过渡结束后，导航栏只根据目标页滚动位置执行普通 / 悬浮形态之间的 360ms CSS 过渡。浏览器前进后退沿用 Astro 滚动恢复；不拦截同页锚点、外链、下载或新标签页操作，返回首页按钮也走同一客户端导航流程。未支持 View Transitions 时直接替换正文，导航栏仍保留；减少动态效果设置禁用动效。原有 Aemeath 的 Swup 不受影响。

Aemeath 与 Pure 的文章、友链和留言页面共用 `src/styles/waline-composer.css`。Waline 工具栏保持在白色编辑框内部，表情面板在其下方作为独立白色圆角框展开；内容区与底部分类栏使用固定高度，隐藏原生悬停预览的空包装层，切换普通表情、颜文字和动态表情时外框尺寸不变。打开时提前关闭文档滚动锚定，避免浏览器把正在编辑的评论框自动滚出视口。手机端推荐友链身份显示为抽屉顶部的全宽黄色提示条，本站主理人身份显示为全宽主题色提示条，文字均居中并位于昵称、邮箱等字段上方；关闭抽屉或恢复桌面布局时回到编辑框内的普通身份标记，重复的“当前模式”隐藏。

文章头部另按上游 `Hero.astro` 适配，使用“封面 → 元信息 → 标题 → 简介 → 正文”的顺序。前景封面左对齐，最大宽度为 `65ch`；即时加载的模糊副图同样最大为 `65ch`，但靠文章容器右侧、向下偏移 16px，形成从封面后方透出的图像。副图沿用上游的 24px 模糊、60% 初始透明度与滚动渐隐，手机窄屏下自然与前景同宽。

整页背景另按上游 `BlogPost.astro` 和 `BaseLayout.astro` 实现：使用文章可选的 `imageColor`（对应上游 `heroImage.color`）；未指定时回退到本站的主题色。背景为文档顶部的一屏高、25% 透明度的渐变，随文档滚动，底端平滑回到主题浅色 / 深色底，不固定在视口上，也不从 LQIP 的单个采样角落取色。例如在文章 frontmatter 中写 `imageColor: "#d58388"` 即可指定其背景强调色，原主题的显示不受这个字段影响。

Pure 只保留文章简介，隐藏原主题摘要并移除独立的 AI 摘要。AI 创作标记由两套主题共用 `PostAiNotice` 的样式，在 Pure 中按 `aiPolished` 水平摆正显示于返回按钮右侧、封面上方的中央位置，无需展开。

目录另按上游 `TOC.astro` 与 `TOCHeading.astro` 适配：保留二至六级标题的嵌套结构、子标题缩进、两行截断、当前可见章节的连续圆角浅底高亮和左侧阅读进度线；读完的章节使用浅灰进度线。目录文字为 14px，标题为 15px，隐藏滚动条并保留长目录的滚动浏览。目录本身使用 sticky，正文滚动时留在视口顶部 80px 的位置。Pure 的 body 使用 overflow:visible，让文档承担滚动，避免 body 成为不实际滚动的祖先容器、阻断 sticky。长目录支持自身滚动和当前项跟随。点击定位预留常驻导航高度，手机目录点击后收起并将焦点移到目标标题。滚动更新使用动画帧调度，并监听内容大小变化和加密文章解锁后的标题插入；切出主题时释放监听。

统计页继续使用原有真实 Umami 数据与控件，Pure 样式移除装饰插画和光效；友链、朋友圈、关于、工具、标签、分类、评论等页面使用 Pure 的中性背景和轻边框。Pure 友链卡片在圆形头像后面加入放大的同源头像副图，低透明度并向文字区域渐隐；推荐友链整张卡片使用淡亮黄色，深色模式对应低亮度暖黄底，推荐标记也使用黄色。装饰副图不参与点击或无障碍朗读，Aemeath 中隐藏。导航直接使用原主题的 `navBarConfig`：主页、文章、站点统计、友链、朋友圈、留言、我的、关于、开往，保留子菜单和页面开关，避免两套主题的导航名称与层级不同。下拉箭头使用 SVG，展开时旋转，同一时刻只展开一个导航菜单。

Pure 页脚沿用简洁分隔线和小字号，展示本站版权、Aemeath 版本、动态运行时长、Umami 今日与累计访客 / 访问量，以及 RSS、站点地图和现有萌 ICP 查询。Pure / Astro 的主题致谢不在页脚展示；上游 Apache-2.0 许可和源码归属仍保留在仓库文档中。

导航栏固定在视口顶部，向下或向上滚动都保持显示；桌面滚动后收窄为 Pure 的悬浮圆角栏，并保留足够宽度显示全部文字。窄于 1024px 时使用可展开导航，子菜单在导航内部排布并支持滚动。两套主题共用阅读进度、跳到评论、回主页和返回顶部控件，只有一组 DOM 与 ID；Pure 使用简洁的 44px 圆角方形浅边框控件，回主页仍使用 Astro 客户端导航。Aemeath 控件保留原来的位置，手机仍预留安全区与评论入口空间。统计页移除插画时一并移除头部最小高度、装饰底色和第二个布局列，避免残留空白。

存储受限时使用 `?siteTheme=pure` 或 `?siteTheme=aemeath` 保存当前选择，并带到站内链接。JavaScript 不可用时显示原有 Aemeath，正文与导航仍可访问。

验证覆盖主题往返、刷新、文章和目录、友链、搜索、浏览器后退、浅色 / 深色、手机导航与键盘操作。截图保存至本地 `.artifacts/site-themes/`，不属于站点静态资源。

Pure 友链普通标签从头像的整体主色生成色系，文字保持实色，背景为 18% 透明度的浅色层（深色模式 14%），不降低文字本身的透明度。“推荐友链”标记保留固定黄色实底，不跟随头像配色；“本站主理人”标记使用主题色实底，卡片也使用不透明的主题浅底。`pnpm friend-colors` 使用现有 Sharp 提取头像的主要色相，忽略透明及近白、近黑区域，按头像 URL 缓存至 `src/constants/friend-avatar-colors.json`；开发启动和构建时自动补齐新增头像。头像 URL 未变但图片已更新时运行 `pnpm friend-colors --refresh`。无法读取的头像使用中性半透明标签，已有缓存继续使用；访客端不额外请求图片或进行 Canvas 取色。

友链卡片底部显示 RSS 最近文章日期，有身份标记的显示在标记旁边，普通友链显示在同一行左侧。日期取所有有效 RSS 文章中的最大值，过滤未来日期，按亚洲上海时区显示完整年月日（例如“最近更新于 2026-10-10”）。构建时与朋友圈共用一次 RSS 刷新及正在执行的请求，失败使用已有快照，无有效日期显示“RSS 暂无”；本地开发直接读取快照，避免进入友链页时等待全站探测。缓存日期在悬停提示中注明。Aemeath 的 HTTP 响应时间显示在卡片右上角，与右下角点击数右对齐。`pnpm friend-latency` 从运行命令的节点执行 GET 探测，收到响应头后停止计时，不下载完整页面；结果保存在 `src/data/friends-latency-snapshot.json`，可在自己的构建流程中刷新。悬停提示注明节点与北京时间，数值不代表访客本机延迟，超时或 HTTP 错误也不会更改友链遮罩。
