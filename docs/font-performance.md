# 文楷字体性能优化

霞鹜文楷的 npm 包已有 Unicode 分片，但页面只要用到分片中的一个字，就会下载整片。构建后再按本站文字生成子集，可以减少下载量，同时保留现在的字形、字体切换和 `font-display: swap`。

## 构建方式

`pnpm build` 在 Astro 输出 HTML 后执行 `scripts/optimize-wenkai-fonts.ts`，随后生成 Pagefind 索引。使用已有的 `subset-font` 依赖；页面切换由 `src/scripts/font-navigation.ts` 准备目标文字的字体，没有新增依赖。

- 公共子集收集首页 HTML、首页直接引用的客户端脚本、当前语言的界面翻译和 ASCII 字符。节日名称等运行时标签也会纳入。
- 其他页面的 HTML 和直接引用脚本补充全站字符集合，在每个原始分片内按最多 128 个字生成共享子集。首页公共字独立保存，浏览器只下载当前文字命中的子集。
- 原始字体继续保留，覆盖子集以外的字符。评论、搜索结果、外部数据中的新字可以按需回退，不会因为构建时没出现而被删除。
- 原字体和子集的 `unicode-range` 互不重复，避免一个已有字符同时触发原始字体和子集下载。
- 所有页面引用相同内容的字体 CSS，公共字体文件使用相同的内容哈希 URL；Swup 切页保留原字体样式节点，复用已经就绪的字形。
- 文楷模式下，切入新页面前按目标页面文字预加载所需字体；默认字体模式跳过。等待最多两秒，字体失败或网络很慢时仍允许页面正常打开。
- 新 CSS 和字体都按最终内容生成文件名，不修改已有哈希资产。保留字体名称与版权元数据，并随生成字体附带 OFL 许可证。

生成内容位于 `dist/_astro/fonts/wenkai/` 和 `dist/_astro/wenkai.*.css`，属于构建产物。

## 本地实测（2026-10-06）

生产预览、Chromium、1440 × 900、文楷模式；记录字体响应体大小，不含 CSS 和请求头。

| 首页字体 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 文楷（19 个外部 WOFF2） | 943.2 KiB | 244.9 KiB |
| 所有外部字体（含代码字体） | 964.6 KiB | 266.3 KiB |

文楷响应体减少约 74%。本次首页没有触发原始大分片。进入长文章后，19 个已使用的公共字体均命中缓存；预览服务仍会进行条件请求，记录到每次约 300 字节的响应头，未重新传输这些字体的响应体。

已验证手机端 390 × 844、默认字体与文楷互切、首页与长文章往返、留言页的动态评论界面，以及 `龘靐齉` 的原字体回退。48 个字体页面的 CSS 保留了原始字符覆盖，所有字体链接和内容哈希检查通过。

以上是 10 月 6 日初版按页面生成子集的测试记录，当时全站生成约 2.91 MiB 的字体。这是整个发布目录的新增字体体积，不是每个页面都要下载的体积。10 月 7 日修复切页闪变后采用共享分块，发布目录规模以当次构建输出为准。

## 页面切换修复（2026-10-07）

初版虽然复用了公共 WOFF2 文件，各页面仍引用不同的字体 CSS。Swup 移除旧 CSS 后，浏览器会销毁对应的 FontFace，缓存命中也需要重新注册和加载。过渡帧中实际记录到已加载文楷从 25 个掉到零，并短暂回退；仅检查切页结束后的外观和网络缓存无法发现这一帧。

修复使用稳定的共享 CSS，避免切页移除字体声明；同时预先加载目标页面文字使用的分块。检查应覆盖过渡帧中的字体就绪状态、样式节点是否保留、首次进入长文章、缓存往返、默认字体模式和移动端，而不仅是最终截图。浏览器可能因其他样式更新重新创建 JavaScript FontFace 对象，不能仅以对象身份判断字体是否发生可见回退。

修复后，48 个字体页面共用一份 CSS，生成 128 个共享子集，整个站点字体子集合计约 1.06 MiB。首次进入长文章的过渡帧没有记录到公共字体未就绪；在 300ms 延迟、约 250 KiB/s 下载速率下切入月刊，字体样式节点保持原样，替换内容前目标文字的字体已就绪。默认字体模式刷新首页只请求代码字体，未请求文楷。

## 验证与限制

字符覆盖检查逐一比较生成 CSS 与原 CSS 的 Unicode 范围，并检查所有字体链接、内容哈希和公共文件的一致性。浏览器验证应同时覆盖首页、长文章、手机端、字体切换，以及子集外的生僻字。

共享分块会包含同一分块中当前页面未用到的其他文字，但能跨页面复用，并保持字体样式稳定。首页公共子集保持独立；动态文字仍可能触发较大的原始分片。首次打开整个文档时仍使用 `font-display: swap`，切页预加载也受两秒等待上限约束。页面下载量不等于整个发布包大小，也不能直接换算成 Lighthouse 分数或首屏时间。

开发服务器仍使用原字体；生成子集的效果需要通过生产构建预览验证。需要隔离构建时，可传入输出目录：`pnpm exec tsx scripts/optimize-wenkai-fonts.ts .astro-build-check/font-audit`。

Unicode 范围按需加载的行为见 [MDN 的 unicode-range 文档](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@font-face/unicode-range)。
