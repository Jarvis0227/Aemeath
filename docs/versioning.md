# 版本号约定

博客主题按 `MAJOR.MINOR.PATCH` 管理版本，更新日志中的 `V` 只是显示前缀：

- **主版本**用于主题架构或整体体验的大幅调整，以及不兼容变更。
- **次版本**用于一组新的访客可见功能；发布后补丁号从 `0` 开始。
- **补丁版本**用于问题修复、性能打磨和兼容维护。

一次相互关联的改动作为一条日志和一个版本发布。版本号代表博客主题版本，不代表更新日志条目总数。`package.json`、`siteConfig.themeVersion`、最新博客日志和 README 版本徽章保持一致。已经发布的历史版本保留原编号；发现重复编号时，只修正重复项，不对整段历史重新编号。

2026 年 10 月 24 日开始使用 `V4.2.0`：它汇总了友链长廊、卡片指标和页面动效的一组访客可见功能。随后以 `V4.2.1` 发布头像与站点图标的视觉更新。此前的 `V4.1.x` 作为已发布历史保留。
